# NLP no Azure

Este domínio cobre **15-20%** do exame AI-900 e foca nas capacidades de Processamento de Linguagem Natural no Azure.

## O que você vai aprender

- **Análise de Texto**: Extração de frases-chave, reconhecimento de entidades nomeadas, análise de sentimento e detecção de idioma
- **Serviços de Fala**: Fala para texto, texto para fala e tradução de fala em tempo real
- **Tradução**: Tradução de texto, tradução de documentos e modelos de tradução personalizados
- **IA Conversacional**: Compreensão de Linguagem Conversacional (CLU) e respostas a perguntas personalizadas

## Serviços do Azure Abordados

| Serviço | Capacidades Principais |
|---------|----------------------|
| Azure AI Language | Sentimento, NER, frases-chave, CLU, Q&A, detecção de PII, sumarização |
| Azure AI Speech | Fala para texto, texto para fala, tradução de fala, reconhecimento de locutor |
| Azure AI Translator | Tradução de texto, tradução de documentos, tradutor personalizado |
