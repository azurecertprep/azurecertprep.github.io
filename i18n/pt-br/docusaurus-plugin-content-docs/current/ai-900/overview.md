# AI-900: Fundamentos de IA do Azure

:::info Detalhes do Exame
**Versão do exame**: Habilidades medidas a partir de maio de 2025 | **Nota para aprovação**: 700/1000 | **Duração**: ~45 minutos | **Custo**: $0 labs
:::

## Para quem é este exame?

O AI-900 valida o conhecimento fundamental de conceitos de machine learning e inteligência artificial no Azure. **Não é necessária experiência técnica profunda** — este exame é projetado para qualquer pessoa iniciando sua jornada em IA, incluindo:

- Profissionais de TI explorando cargas de trabalho de IA
- Tomadores de decisão de negócios avaliando capacidades de IA
- Estudantes interessados em carreiras de IA e machine learning
- Desenvolvedores que desejam uma compreensão ampla dos serviços de IA do Azure

## Habilidades resumidas

| Domínio | Peso | Desafios |
|---------|------|----------|
| Descrever cargas de trabalho e considerações de IA | 15–20% | 01–04 |
| Descrever princípios fundamentais de machine learning no Azure | 20–25% | 05–09 |
| Descrever recursos de cargas de trabalho de visão computacional no Azure | 15–20% | 10–13 |
| Descrever recursos de cargas de trabalho de Processamento de Linguagem Natural no Azure | 15–20% | 14–18 |
| Descrever recursos de cargas de trabalho de IA generativa no Azure | 15–20% | 19–24 |

:::tip Estrutura dos Desafios
Todos os 24 desafios são **baseados em exploração e completamente gratuitos** (custo $0). Eles utilizam o Portal Azure, as camadas gratuitas dos serviços Azure AI e o Azure AI Studio. O foco é entender conceitos de IA através de exploração prática — não construir pipelines de ML em produção.
:::

## Como usar esta preparação

Cada desafio segue um formato amigável para iniciantes:

| Seção | Propósito |
|-------|-----------|
| **Habilidades do Exame Cobertas** | Habilidades oficiais que este desafio aborda |
| **Visão Geral** | Explicação amigável do conceito de IA |
| **Explorar** | Exploração passo a passo dos serviços Azure AI |
| **Experimente** | Experimentos práticos opcionais com serviços de camada gratuita |
| **Conceitos-Chave** | Resumo dos pontos críticos |
| **Verificação de Conhecimento** | Questões de múltipla escolha no estilo do exame |
| **Saiba Mais** | Links para o guia de estudo e Microsoft Learn |

## Pré-requisitos

- **Conta Azure** — [Conta Gratuita Azure](https://azure.microsoft.com/free/) (camada gratuita é suficiente para todos os desafios do AI-900)
- **Navegador web** — A maioria das tarefas usa o Portal Azure e Azure AI Studio
- **Sem experiência prévia em IA/ML** — Este exame é verdadeiramente fundamental
- **Sem programação necessária** — Conceitos são explorados através da interface do portal

:::tip Custo Zero
Cada desafio neste guia custa $0. Utilizamos as camadas gratuitas dos serviços Azure AI, exploração do Azure AI Studio e demonstrações baseadas no portal. Você não criará recursos cobráveis acidentalmente.
:::
