# Capstone

O desafio capstone reúne **todos os cinco domínios do AI-900** em um único cenário de ponta a ponta.

## O que você vai demonstrar

- Mapear requisitos de negócios para serviços Azure AI apropriados
- Escolher entre Computer Vision, NLP, Machine Learning e IA Generativa
- Projetar arquiteturas multi-serviço que integram capacidades Azure AI
- Aplicar princípios de IA responsável em todos os cenários
- Tomar decisões arquiteturais (pré-construído vs. personalizado, tempo real vs. lote)

## Desafio

| Desafio | Tópico | Foco |
|---------|--------|------|
| 24 | End-to-End: Desafio de Portfólio Azure AI | Todos os domínios — tomada de decisão baseada em cenários |

Este desafio simula perguntas de cenário no estilo do exame onde você deve selecionar o serviço e abordagem corretos para um problema de negócios específico.
