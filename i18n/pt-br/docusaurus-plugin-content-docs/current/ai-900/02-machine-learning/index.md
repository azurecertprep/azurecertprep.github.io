# Machine Learning no Azure

Este domínio cobre **15-20%** do exame AI-900. Você aprenderá conceitos fundamentais de ML (regressão, classificação, clustering), entenderá deep learning e Transformers, e explorará as capacidades do workspace do Azure Machine Learning.

## Desafios neste domínio

| # | Desafio | Tópicos principais |
|---|---------|-------------------|
| 05 | Regressão em Machine Learning | Previsão de valores numéricos, features vs labels, métricas de avaliação |
| 06 | Classificação em Machine Learning | Binária vs multiclasse, aprendizado supervisionado, precisão/recall |
| 07 | Clustering em Machine Learning | Aprendizado não supervisionado, K-Means, segmentação de clientes |
| 08 | Deep Learning e Transformers | Redes neurais, CNNs, mecanismo de atenção, GPT/BERT |
| 09 | Workspace do Azure Machine Learning | AutoML, Designer, computação, endpoints, registro de modelos |
