# IA Generativa no Azure

Este domínio cobre **15-20%** do exame AI-900 e foca em conceitos de IA generativa e serviços Azure.

## O que você vai aprender

- **Fundamentos de IA Generativa**: LLMs, modelos fundacionais, tokens, alucinações
- **Azure OpenAI Service**: Modelos (GPT-4, DALL-E, Whisper), implantações, endpoints
- **Azure AI Foundry**: Catálogo de modelos, modelo hub/projeto, prompt flow, avaliação
- **Engenharia de Prompt**: Mensagens de sistema, exemplos few-shot, temperatura, grounding
- **IA Responsável para GenAI**: Filtragem de conteúdo, injeção de prompt, transparência, direitos autorais

## Serviços Azure Abordados

| Serviço | Capacidades Principais |
|---------|----------------------|
| Azure OpenAI Service | GPT-4o, GPT-4, GPT-3.5, DALL-E, Whisper, embeddings |
| Azure AI Foundry | Catálogo de modelos, prompt flow, avaliação, implantações |
