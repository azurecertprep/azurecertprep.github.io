# Estou Pronto para o AI-102?

Antes de mergulhar nos desafios, reserve alguns minutos para avaliar sua prontidão. O AI-102 é um exame de nível **Associate** que pressupõe experiência prática em programação e familiaridade com conceitos de IA. Diferente do AI-900, este exame exige que você escreva código que integre serviços Azure AI em aplicações.

## Como Interpretar Seus Resultados

### Maioria ✅: Você está pronto!
Vá direto para a [Configuração do Laboratório](/docs/ai-102/lab-setup) e comece o Desafio 01.

### Mistura de ✅ e ⚠️: Você está quase pronto
Comece os desafios, mas reserve 2–4 semanas de estudo focado. Use os links de **Recursos de Aprendizagem** em cada desafio para preencher as lacunas conforme avança.

### Vários ❌: Comece pelos fundamentos primeiro
Considere estes recursos antes de iniciar o AI-102:
- [AI-900: Azure AI Fundamentals](/docs/ai-900/overview) — Construa conceitos fundamentais de IA e Azure AI
- [Python for Beginners](https://learn.microsoft.com/en-us/training/paths/beginner-python/) — Caminho gratuito no Microsoft Learn
- [Azure OpenAI Getting Started](https://learn.microsoft.com/en-us/azure/ai-services/openai/quickstart) — Início rápido prático

:::tip Nenhuma experiência com IA?

Tudo bem! A certificação AI-900 (Azure AI Fundamentals) é um excelente ponto de partida. Ela cobre os conceitos por trás dos serviços de IA sem exigir código. Muitos candidatos fazem o AI-900 primeiro, desenvolvem habilidades de programação e depois encaram o AI-102.

:::

## Expectativas de Experiência

De acordo com a Microsoft, candidatos ao AI-102 devem ter:

- **1+ ano** de experiência com Python ou C#
- Familiaridade com **REST APIs e SDKs**
- Compreensão de **serviços Azure** (assinaturas, grupos de recursos, deployment)
- Conhecimento de **fundamentos de IA/ML** (treinamento, inferência, modelos, avaliação)
- Experiência com **noções de DevOps** (Git, conceitos de CI/CD, containers)

:::note Não tem um ano completo de experiência?

Estes desafios são projetados para acelerar seu aprendizado. Cada desafio é autocontido com abas para Python, C# e REST. Se você aprende rápido e consegue programar com confiança, pode construir experiência prática equivalente completando todos os 49 desafios em 4–6 semanas de estudo focado.

:::
