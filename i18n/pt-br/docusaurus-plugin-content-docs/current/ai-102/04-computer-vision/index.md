# Soluções de Visão Computacional

Este domínio cobre a construção de aplicações que podem ver e compreender imagens, documentos e vídeos usando os serviços Azure AI Vision. Ele representa **10–15%** do exame AI-102.

Você trabalhará com a API Image Analysis 4.0 para tarefas de visão de propósito geral, Custom Vision para classificação e detecção específicas de domínio, a Read API para OCR, Face API para cenários de reconhecimento facial e Video Indexer para análise de conteúdo de vídeo. Cada desafio foca em uma capacidade específica com cenários do mundo real.

O exame testa tanto padrões de uso do SDK quanto a compreensão de quando usar cada serviço de visão. Saiba a diferença entre modelos pré-construídos (Image Analysis) e modelos treinados customizados (Custom Vision), e quando OCR vs Document Intelligence é a escolha correta.

## O Que Você Vai Aprender

- Analisar imagens com Azure AI Vision (legendas, tags, objetos, pessoas)
- Treinar e implantar modelos customizados de classificação de imagem
- Implementar detecção customizada de objetos com bounding boxes
- Extrair texto de imagens com OCR (Read API)
- Detectar e analisar rostos (com considerações de IA responsável)
- Analisar conteúdo de vídeo com Video Indexer

## Habilidades Avaliadas

- Analisar imagens usando Azure AI Vision Image Analysis
- Implementar classificação customizada de imagem e detecção de objetos
- Ler e extrair texto de imagens e documentos
- Implementar detecção, verificação e identificação facial
- Analisar vídeo com Azure Video Indexer

- Domínio 1 (Planejar e Gerenciar) concluído ou conhecimento equivalente
