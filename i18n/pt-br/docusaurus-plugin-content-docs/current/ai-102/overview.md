# AI-102: Azure AI Engineer

:::info Detalhes do Exame
**Versão do exame**: Habilidades medidas a partir de maio de 2025 | **Nota para aprovação**: 700/1000 | **Duração**: ~100-120 minutos | **Custo**: ~$20-50 para labs
:::

:::warning Aposentadoria do Exame
Este exame será aposentado em **30 de junho de 2026**. Planeje seu cronograma de preparação adequadamente. A Microsoft pode substituí-lo por uma certificação atualizada alinhada ao Azure AI Foundry.
:::

## Para quem é este exame?

O AI-102 valida a capacidade de projetar, construir e implantar soluções de IA usando os serviços Azure AI. Esta é uma certificação **prática e orientada a código**, projetada para:

- Desenvolvedores de IA construindo aplicações inteligentes
- Cientistas de dados em transição para engenharia de IA em produção
- Engenheiros de software integrando IA/ML em aplicações
- Arquitetos de nuvem projetando soluções com IA
- Engenheiros DevOps implantando e gerenciando cargas de trabalho de IA

## Habilidades resumidas

| Domínio | Peso | Desafios |
|---------|------|----------|
| Planejar e gerenciar uma solução Azure AI | 20–25% | 01–10 |
| Implementar soluções de IA generativa | 15–20% | 11–20 |
| Implementar soluções de agentes de IA | 5–10% | 21–23 |
| Implementar soluções de visão computacional | 10–15% | 24–30 |
| Implementar soluções de processamento de linguagem natural | 15–20% | 31–39 |
| Implementar knowledge mining e document intelligence | 15–20% | 40–49 |

:::tip Estrutura dos Desafios
Todos os 49 desafios são **orientados a código** com abas **Python / C# / REST**. Cada desafio inclui implantação de recursos reais do Azure AI, escrita de código de integração e validação programática de resultados. Espere trabalhar com SDKs, APIs REST e Azure AI Studio.
:::

## Como usar esta preparação

Cada desafio segue um formato focado no desenvolvedor:

| Seção | Propósito |
|-------|-----------|
| **Habilidades do Exame Cobertas** | Habilidades oficiais que este desafio aborda |
| **Cenário** | Problema do mundo real que contextualiza o desafio |
| **Arquitetura** | Diagrama dos componentes da solução |
| **Tarefas** | Passo a passo com abas Python / C# / REST |
| **Validação** | Verificações programáticas para validar sua solução |
| **Quebre & Conserte** | Configurações incorretas deliberadas para diagnosticar |
| **Verificação de Conhecimento** | Questões no estilo do exame |
| **Limpeza** | Scripts para excluir recursos e evitar custos |

## Pré-requisitos

- **Experiência em programação** — Python ou C# (a maioria dos desafios fornece ambos)
- **Assinatura Azure** — [Conta Gratuita Azure](https://azure.microsoft.com/free/) com crédito de $200 recomendado
- **Ambiente de desenvolvimento** — VS Code com extensões Azure, ou GitHub Codespaces
- **Azure CLI** — Autenticada e configurada
- **Conhecimento AI-900** — Compreensão de conceitos fundamentais de IA (recomendado, não obrigatório)

:::warning Custos dos Labs
Alguns desafios criam recursos cobráveis (Azure OpenAI, Azure AI Search, Azure AI Document Intelligence). Sempre execute os scripts de limpeza após completar um desafio. Custo total estimado para todos os labs: $20-50 com limpeza cuidadosa.
:::
