# Configuração do Laboratório

Os desafios do AZ-900 foram projetados para serem **completamente gratuitos**. Você não criará nenhum recurso cobrável — apenas explorará o Portal Azure e usará ferramentas gratuitas.

## O que você precisa

| Requisito | Como obter | Custo |
|-----------|-----------|-------|
| Conta Azure | [azure.microsoft.com/free](https://azure.microsoft.com/free/) | Gratuito |
| Navegador web | Chrome, Edge, Firefox ou Safari | Gratuito |
| Azure Cloud Shell | Integrado ao Portal Azure | Gratuito (5 GB de armazenamento) |

## Passo 1: Criar uma conta gratuita Azure

1. Acesse [azure.microsoft.com/free](https://azure.microsoft.com/free/)
2. Clique em **Start free**
3. Entre com uma conta Microsoft (ou crie uma)
4. Complete a verificação (telefone + cartão de crédito para identidade — você não será cobrado)
5. Agora você tem:
   - **$200 de crédito gratuito** por 30 dias
   - **12 meses** de serviços gratuitos populares
   - **Sempre gratuitos** serviços (25+)

:::tip Sem cartão de crédito?
Se você é estudante, use o [Azure for Students](https://azure.microsoft.com/free/students/) — $100 de crédito **sem necessidade de cartão de crédito**.
:::

## Passo 2: Acessar o Portal Azure

1. Acesse [portal.azure.com](https://portal.azure.com)
2. Entre com sua conta Azure
3. Você deve ver a página inicial do Portal Azure

É isso! Você está pronto para começar os desafios.

## Passo 3: Abrir o Azure Cloud Shell (opcional)

Alguns desafios oferecem alternativas via Azure CLI. Para usá-las:

1. No Portal Azure, clique no ícone do **Cloud Shell** (ícone de terminal na barra superior)
2. Escolha **Bash** ou **PowerShell**
3. Se solicitado, crie uma conta de armazenamento (gratuita com sua subscription)
4. Agora você tem um terminal com Azure CLI pré-instalado

:::info Lembrete de custo
Os desafios do AZ-900 NUNCA exigem que você crie recursos cobráveis. Se um desafio pede para criar algo (como um resource group), é sempre gratuito. Resource groups em si custam $0 — são apenas containers organizacionais.
:::

## Ferramentas usadas neste guia

| Ferramenta | O que é | Custo |
|-----------|---------|-------|
| Portal Azure | Interface de gerenciamento baseada na web | Gratuito |
| Azure Cloud Shell | Terminal no navegador com ferramentas CLI | Gratuito |
| Calculadora de Preços Azure | Estimar custos de serviços Azure | Gratuito |
| Calculadora TCO | Comparar custos on-premises vs. nuvem | Gratuito |
| Centro de administração Microsoft Entra | Portal de gerenciamento de identidade | Gratuito |

## Solução de problemas

| Problema | Solução |
|----------|---------|
| Não consigo criar conta gratuita | Tente um endereço de email ou navegador diferente |
| Cloud Shell não abre | Certifique-se de ter uma subscription ativa |
| Portal carrega lentamente | Tente outro navegador ou limpe o cache |
| "No subscriptions found" | Verifique se está logado com a conta correta |
