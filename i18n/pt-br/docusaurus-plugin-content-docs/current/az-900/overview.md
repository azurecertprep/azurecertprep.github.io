# AZ-900: Fundamentos do Azure

:::info Detalhes do Exame
**Versão do exame**: Habilidades medidas a partir de 14 de janeiro de 2026 | **Nota de aprovação**: 700/1000 | **Duração**: ~45 minutos | **Custo**: $0 nos labs
:::

## Para quem é este exame?

O AZ-900 é o seu ponto de entrada nas certificações Azure. Ele valida o conhecimento fundamental sobre conceitos de nuvem, serviços Azure, gerenciamento e governança do Azure. **Nenhuma experiência técnica é necessária** — este exame foi projetado para qualquer pessoa iniciando sua jornada na nuvem, incluindo:

- Profissionais de TI em transição para a nuvem
- Stakeholders de negócios que precisam entender as capacidades da nuvem
- Estudantes explorando carreiras em computação em nuvem
- Equipes de vendas e compras avaliando o Azure

## Habilidades em resumo

| Domínio | Peso | Desafios |
|---------|------|----------|
| Descrever conceitos de nuvem | 25–30% | 01–06 |
| Descrever arquitetura e serviços Azure | 35–40% | 07–18 |
| Descrever gerenciamento e governança Azure | 30–35% | 19–24 |

:::tip Estrutura dos Desafios
Todos os 24 desafios são **baseados em exploração e completamente gratuitos** (custo $0). Eles utilizam o Portal Azure, Azure Cloud Shell e serviços de nível gratuito. O foco é entender conceitos através de navegação prática — não construir infraestrutura complexa.
:::

## Pré-requisitos

- **Conta Azure** — [Conta Gratuita Azure](https://azure.microsoft.com/free/) (sem necessidade de cartão de crédito para a maioria das explorações do AZ-900)
- **Navegador web** — É só isso! A maioria das tarefas usa o Portal Azure
- **Sem experiência prévia em Azure** — Este exame é verdadeiramente fundamental

:::tip Custo Zero
Todos os desafios neste guia custam $0. Utilizamos apenas o Portal Azure, Azure Cloud Shell (gratuito), a Calculadora de Preços (gratuita) e exploração somente leitura dos serviços Azure. Você não criará acidentalmente recursos cobráveis.
:::
