# Challenge 31: Infrastructure as Code strategy

:::info Platform: comparison

:::

## Exam skills

- Recommend a configuration management technology for application infrastructure
- Define an IaC strategy, including source control and automation of testing and deployment

## Scenario

Contoso manages 200+ Azure resources across 5 environments. Infrastructure changes are done manually via Portal, causing drift and inconsistency. Design an IaC strategy with CI/CD for infrastructure.
