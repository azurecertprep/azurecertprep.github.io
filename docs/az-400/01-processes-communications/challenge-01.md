# Challenge 01: Design flow of work

:::info Platform: GitHub-first

:::

## Exam skills

- Design and implement a structure for the flow of work, including GitHub Flow

## Scenario

Your team at Contoso Ltd is adopting DevOps practices. Currently, developers work on long-lived feature branches that often diverge weeks from main, causing painful merges. The team lead asks you to design a branching workflow that enables continuous integration while supporting release cycles.
