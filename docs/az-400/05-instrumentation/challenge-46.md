# Challenge 46: Azure Monitor integration with DevOps

:::info Platform: comparison

:::

## Exam skills

- Configure Azure Monitor and Azure Monitor Logs to integrate with DevOps tools

## Scenario

Contoso deploys 5 times per day but has no visibility into whether deployments impact application health. Integrate Azure Monitor with the CI/CD pipeline to create deployment annotations and automated rollback triggers.
