# Challenge 39: Authentication and identity for DevOps

:::info Platform: comparison

:::

## Exam skills

- Choose between Microsoft Entra service principals and managed identities for Azure resources
- Implement secretless authentication (workload identity federation/OIDC)

## Scenario

Contoso's pipelines use a shared service principal with a client secret that expires yearly, causing outages. Migrate to workload identity federation for secretless authentication.
