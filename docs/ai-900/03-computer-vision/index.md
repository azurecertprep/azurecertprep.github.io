# Computer Vision on Azure

This domain covers **15-20%** of the AI-900 exam. You'll learn about image classification, object detection, OCR, and face detection — including the Azure services that power each capability and the ethical considerations around facial recognition.

## Challenges in this domain

| # | Challenge | Key topics |
|---|-----------|-----------|
| 10 | Image Classification | Single-label, multi-label, confidence scores, Custom Vision |
| 11 | Object Detection | Bounding boxes, localization, counting objects |
| 12 | Optical Character Recognition (OCR) | Read API, Document Intelligence, printed/handwritten text |
| 13 | Face Detection and Analysis | Detection vs recognition, Limited Access policy, ethical AI |
