# NLP on Azure

This domain covers **15-20%** of the AI-900 exam and focuses on Natural Language Processing capabilities in Azure.

## What you'll learn

- **Text Analytics**: Key phrase extraction, named entity recognition, sentiment analysis, and language detection
- **Speech Services**: Speech-to-text, text-to-speech, and real-time speech translation
- **Translation**: Text translation, document translation, and custom translation models
- **Conversational AI**: Conversational Language Understanding (CLU) and custom question answering

## Azure Services Covered

| Service | Key Capabilities |
|---------|-----------------|
| Azure AI Language | Sentiment, NER, key phrases, CLU, Q&A, PII detection, summarization |
| Azure AI Speech | Speech-to-text, text-to-speech, speech translation, speaker recognition |
| Azure AI Translator | Text translation, document translation, custom translator |
