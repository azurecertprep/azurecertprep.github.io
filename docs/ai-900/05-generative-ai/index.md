# Generative AI on Azure

This domain covers **15-20%** of the AI-900 exam and focuses on generative AI concepts and Azure services.

## What you'll learn

- **Generative AI Fundamentals**: LLMs, foundation models, tokens, hallucinations
- **Azure OpenAI Service**: Models (GPT-4, DALL-E, Whisper), deployments, endpoints
- **Azure AI Foundry**: Model catalog, hub/project model, prompt flow, evaluation
- **Prompt Engineering**: System messages, few-shot examples, temperature, grounding
- **Responsible AI for GenAI**: Content filtering, prompt injection, transparency, copyright

## Azure Services Covered

| Service | Key Capabilities |
|---------|-----------------|
| Azure OpenAI Service | GPT-4o, GPT-4, GPT-3.5, DALL-E, Whisper, embeddings |
| Azure AI Foundry | Model catalog, prompt flow, evaluation, deployments |
