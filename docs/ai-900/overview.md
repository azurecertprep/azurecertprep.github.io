# AI-900: Azure AI Fundamentals

:::info Exam Details
**Exam version**: Skills measured as of May 2025 | **Passing score**: 700/1000 | **Duration**: ~45 minutes | **Cost**: $0 labs
:::

## Who is this for?

The AI-900 validates foundational knowledge of machine learning and artificial intelligence concepts on Azure. **No deep technical experience required** — this exam is designed for anyone beginning their AI journey, including:

- IT professionals exploring AI workloads
- Business decision-makers evaluating AI capabilities
- Students interested in AI and machine learning careers
- Developers who want a broad understanding of Azure AI services

## Skills at a glance

| Domain | Weight | Challenges |
|--------|--------|------------|
| Describe AI workloads and considerations | 15–20% | 01–04 |
| Describe fundamental principles of machine learning on Azure | 20–25% | 05–09 |
| Describe features of computer vision workloads on Azure | 15–20% | 10–13 |
| Describe features of Natural Language Processing workloads on Azure | 15–20% | 14–18 |
| Describe features of generative AI workloads on Azure | 15–20% | 19–24 |

:::tip Challenge Structure
All 24 challenges are **exploration-based and completely free** ($0 cost). They use the Azure Portal, Azure AI services free tiers, and Azure AI Studio. The focus is on understanding AI concepts through hands-on exploration — not building production ML pipelines.
:::

## How to use this prep

Each challenge follows a beginner-friendly format:

| Section | Purpose |
|---------|---------|
| **Exam Skills Covered** | Official skills this challenge addresses |
| **Overview** | Beginner-friendly explanation of the AI concept |
| **Explore** | Step-by-step exploration of Azure AI services |
| **Try It** | Optional hands-on experiments with free-tier services |
| **Key Concepts** | Summary of critical takeaways |
| **Knowledge Check** | Exam-style multiple choice questions |
| **Learn More** | Links to study guide and Microsoft Learn |

## Prerequisites

- **Azure account** — [Azure Free Account](https://azure.microsoft.com/free/) (free tier is sufficient for all AI-900 challenges)
- **Web browser** — Most tasks use the Azure Portal and Azure AI Studio
- **No prior AI/ML experience** — This exam is truly foundational
- **No programming required** — Concepts are explored through the portal UI

:::tip Zero Cost
Every challenge in this guide costs $0. We use Azure AI services free tiers, Azure AI Studio exploration, and portal-based demonstrations. You won't accidentally create billable resources.
:::
