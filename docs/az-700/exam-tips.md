## Exam format

- **Questions**: ~40-60 questions
- **Duration**: 100-120 minutes
- **Passing score**: 700/1000
- **Question types**: Multiple choice, drag-and-drop, case studies, hot area (diagram-based)

## Key domain weights

| Domain | Weight | Study priority |
|--------|--------|---------------|
| Core Networking | 25-30% | Highest — master VNets, DNS, routing |
| Connectivity | 20-25% | High — VPN and ExpressRoute heavily tested |
| App Delivery | 15-20% | Medium — know when to use which LB solution |
| Private Access | 10-15% | Medium — PE/PLS DNS integration is critical |
| Network Security | 15-20% | High — NSG + Firewall + WAF scenarios |

## Top study recommendations

1. **Know the decision matrix** — When to use Load Balancer vs Application Gateway vs Front Door vs Traffic Manager
2. **DNS is everywhere** — Private DNS zones, Private Resolver, split-horizon DNS for hybrid
3. **Routing depth** — UDRs, Route Server BGP, forced tunneling, effective routes
4. **ExpressRoute details** — Global Reach vs FastPath vs Direct, peering types, encryption options
5. **Firewall vs NSG vs WAF** — Each has a specific layer and purpose
